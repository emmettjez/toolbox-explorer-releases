# Toolbox Explorer

Toolbox Explorer is a file explorer optimized for easily viewing media files and image
sequences in a complex nested directory structure.

### ⬇ [Download Toolbox Explorer](https://github.com/emmettjez/toolbox-explorer-releases/releases/latest/download/toolbox-explorer-latest.pkg)

macOS, Apple silicon. Open the `.pkg` — it installs into your Applications folder and asks
for no password.
