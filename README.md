# Toolbox Explorer

Toolbox Explorer is a file browser for image sequences and renders. Point it at a folder and it scans the whole tree, folds every image sequence into one row with its frame range, and stacks older versions under the newest. It previews EXR, DPX and ProRes by decoding the frame under the playhead, so there is nothing to build first and nothing to wait for.

### ⬇ [Download Toolbox Explorer](https://github.com/emmettjez/toolbox-explorer-releases/releases/latest/download/toolbox-explorer-latest.pkg)

macOS, Apple silicon. Open the `.pkg` — it installs into your Applications folder and asks for no password.

Once installed, Toolbox Explorer tells you when a new version is available and updates itself. You should only need to download it once.
